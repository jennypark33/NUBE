# NUBE’ — HOME & AWAY 웹사이트

포트폴리오·전시용 웹사이트입니다. 실제 결제는 없고, 장바구니·선물하기·주문 완료까지 브라우저 안에서만 동작합니다.

## GitHub Pages에 올리는 방법

1. GitHub에서 새 저장소(Repository)를 만듭니다. 예: `nube-web` (Public)
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더 안의 `index.html`, `README.md`, `images` 폴더를 통째로 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
3. 저장소의 **Settings → Pages**로 가서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 같은 화면 위쪽에 `https://아이디.github.io/nube-web/` 주소가 나타납니다.

수정할 때는 저장소에서 파일을 다시 올리거나 연필 아이콘으로 바로 고치면 몇 분 안에 사이트에 반영됩니다.

## 이미지 넣기

피그마에서 해당 레이어를 선택하고 오른쪽 아래 **Export**에서 내보낸 뒤, 아래 이름 그대로 `images` 폴더에 넣으세요.
파일이 없으면 그 자리에 파일 이름이 표시되니, 빠진 이미지를 바로 찾을 수 있습니다.

| 파일 이름 | 피그마 레이어 | 형식 / 권장 크기 |
|---|---|---|
| `hero.jpg` | 히어로 메인 키비주얼 | JPG 2x (2880×1640) |
| `brand-illustration.png` | 브랜드 스토리 원숭이·등나무 일러스트 (3구 1) | PNG 투명 배경, 가로 1680 이상 |
| `label-01.png` ~ `label-05.png` | 라벨 섹션 향 그래픽 5종 (포도, 석류, 패션후르츠, 능소화, 시트러스) | PNG 투명 배경 2x (452×452) |
| `scent-01.png` ~ `scent-05.png` | 향 챕터 큰 일러스트 5종 (원본 비율) | PNG 투명 배경, 가로 1200 |
| `stationery.png` | 스테이셔너리 웰컴 카드 일러스트 (5구) | PNG 2x |
| `symbol.png` | 웰컴 카드 위 작은 심볼 | PNG 2x (80×80) |
| `gift-trio.jpg` | THE TRIO GARDEN COLLECTION 패키지 사진 | JPG, 가로 1300 |
| `gift-five.jpg` | FIVE-PIECE SET 패키지 사진 | JPG, 가로 1300 |
| `closing.jpg` | 엔딩 사진 (비누 + 등나무꽃) | JPG 2x (1920×1720) |

- 일러스트는 배경을 투명하게 내보내야 향마다 다른 배경색(Mist 컬러)이 비쳐 보입니다.
- 향 챕터 일러스트 중 피그마에서 180° 회전돼 있는 것(04, 05)은 회전된 모습 그대로 내보내면 됩니다.
- JPG는 1MB 이하로 줄이면 페이지가 빨리 열립니다. (예: squoosh.app)

NUBE’ 로고(내비, 엔딩 세로 로고, 명함)는 피그마 로고 벡터를 코드에 그대로 넣어서 따로 이미지가 필요 없습니다.

## 폰트

- 영문: Minion Pro — 컴퓨터에 설치돼 있으면 그대로 보이고, 없으면 비슷한 EB Garamond로 보입니다. 모든 방문자에게 Minion Pro로 보이게 하려면 Adobe Fonts 웹 프로젝트를 만들어 `<head>`에 Adobe가 주는 링크 한 줄을 추가하세요.
- 한글: 조선일보명조 — 설치돼 있지 않아도 무료 웹폰트로 불러옵니다.

## 들어 있는 기능

- 스크롤하면 요소가 차례로 부드럽게 나타나는 모션 (한 번만 재생)
- 버튼·메뉴·키워드·라벨 카드·컬러칩 호버 모션
- 커서 반응: 향 일러스트가 커서 방향으로 미세하게 움직임, 브랜드 스토리·웰컴 카드 일러스트 패럴랙스, 주요 버튼 마그네틱
- 향 챕터 수량 선택(0에서 시작) → 장바구니 담기 / 선물하기
- 3구 세트 향 3가지 선택, 5구 세트
- 장바구니: 수량 변경, 삭제, 리본 포장, 합계, 주문 완료 (새로고침해도 유지)
- 선물하기: 받는 방법 전환, 이름·연락처 입력 확인, 주소 입력, 메시지 카드(100자), 포장 선택
- 명함: 누르면 종이가 뒤집히며 뒷면이 보임 (마우스를 올리면 커서 방향으로 살짝 기울어짐). 명함은 이미지 없이 코드로 그려져 있어서 따로 넣을 파일이 없습니다. 뒷면 이름·이메일·전화번호는 `index.html`의 `<!-- 명함 -->` 부분에서 고칠 수 있습니다.
- 휴대폰 화면 대응, 키보드 Esc로 창 닫기, ‘동작 줄이기’ 설정 사용자는 모션 없이 표시

가격은 피그마 시안의 임시값(단품 ₩24,000, 3구 ₩68,000, 5구 ₩110,000, 리본 포장 ₩3,000)입니다. `index.html` 아래쪽 `const PRICE`에서 바꿀 수 있습니다.
